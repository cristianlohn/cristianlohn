## Projetos em destaque

### ScreenHoard — produtividade e evidências

Utilitário para Windows que reúne histórico da área de transferência, captura de tela, gravação de evidências em GIF, OCR e ferramentas de inspeção visual.

**Tecnologias:** Tauri, Rust, React, TypeScript e SQLite.

[Explorar o projeto](https://github.com/cristianlohn/ScreenHoard) · [Versões e downloads](https://github.com/cristianlohn/ScreenHoard/releases) · [Manual de uso](https://github.com/cristianlohn/ScreenHoard/blob/main/USER_GUIDE.md)

### Playwright MarkL — testes de gerenciamento de tarefas

Automação de cenários de cadastro, conclusão e exclusão de tarefas, com validações de duplicidade e campos obrigatórios. A estrutura utiliza Page Objects, fixtures e preparação de dados por API.

**Tecnologias:** Playwright e TypeScript.

[Explorar os testes](https://github.com/cristianlohn/playwright-markL/tree/master/tests)

### Cypress — estrutura para automação de API

Projeto de exemplo com organização em serviços e lógica de testes, configuração de relatórios e arquivo de pipeline para Azure DevOps.

**Tecnologias:** Cypress, TypeScript, Mochawesome e JUnit Reporter.

[Explorar o projeto](https://github.com/cristianlohn/Cypress-auto-run-example)
